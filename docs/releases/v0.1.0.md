## Highlights

- **JustConnect comes to Linux.** The first Linux release supports x64 in both Automatic routing and Local proxy only modes. Choose a `.deb` or a portable archive. The `.deb` is built and tested on Debian 13. [Linux requirements](https://github.com/wtalioy/JustConnect/blob/v0.1.0/README.md#linux-requirements).
- **Install updates from JustConnect.** Starting with this version, **Check for updates → Install update** downloads and verifies the update, disconnects safely, and reopens JustConnect after installation. This works with the Windows installer, a writable macOS app bundle, and the Linux `.deb`. Portable builds update from the release page.
- **Bring campus rules straight into Clash Verge Rev.** In Local proxy only mode, connect and choose **Import into Clash Verge Rev**, then use **Reactivate Profiles** in Clash Verge Rev. The import keeps your existing global script and saves a backup. Both import and copy also pick up eligible domains from your per-domain DNS settings. [Clash setup](https://github.com/wtalioy/JustConnect/blob/v0.1.0/README.md#local-proxy-only).

## Fixes and improvements

- Fixed access to some gateway-published resources, including Fudan eLearning assets and the academic affairs portal.
- Preserved saved sign-ins when the gateway temporarily fails to return account details.
- Improved Windows DNS discovery and handling of transient system proxy errors. On macOS, JustConnect now retries briefly when system network settings are busy.
- Refreshed confirmation and update dialogs, blended macOS title bars into the window, and restored transparent taskbar icons on Windows.
- Reduced memory allocations in tunnel setup and packet forwarding.
