## Highlights

- **Local proxy only.** Choose this mode in **Edit connection** to send campus traffic through a local SOCKS5 proxy. No system routes, DNS, or proxy settings change, and no network helper is needed. Automatic routing is still the default.
- **Clash rules from your gateway.** Once connected, select **Copy Clash Extend Script** to add campus routes with their protocol and port limits while keeping your existing rules. [Setup guide](https://github.com/wtalioy/JustConnect/blob/v0.0.2/README.md#local-proxy-only).
- **Faster, lighter.** Single-node gateways connect without waiting for extra probes, background updates do less UI work, and Windows downloads are smaller.
