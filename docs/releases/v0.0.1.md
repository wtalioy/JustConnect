This is the first public release of JustConnect, an aTrust client for campus networks. Use your usual browser and SSH client after connecting. The app includes a Fudan University profile and supports custom aTrust gateways.

### Downloads

| Platform | Recommended | No-install option |
| --- | --- | --- |
| Windows x64 | `JustConnect-v0.0.1-windows-x64-setup.exe` | `JustConnect-v0.0.1-windows-x64.zip` |
| Windows ARM64 | `JustConnect-v0.0.1-windows-arm64-setup.exe` | `JustConnect-v0.0.1-windows-arm64.zip` |
| macOS Apple silicon | `JustConnect-v0.0.1-macos-arm64.dmg` | |
| macOS Intel | `JustConnect-v0.0.1-macos-x64.dmg` | |

On Windows, the installer runs for your account and lets you choose the destination and whether to create a Start menu shortcut. For the ZIP, extract all files before launching `JustConnect.exe`. Both options require the WebView2 Runtime for sign-in.

On macOS 14.4 or later, open the DMG and drag JustConnect to Applications. Windows installers are unsigned and macOS builds are not notarized, so your system may prompt you at first launch. The first connection may also require permission to manage network settings.

Use `SHA256SUMS.txt` to verify your download. The `JustConnect-v0.0.1-source.tar.gz` archive contains the source for these builds.
