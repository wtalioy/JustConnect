JustConnect 的首个公开版本，面向 Windows 和 macOS 的 aTrust 校园网络用户。

连接后可以继续用原有浏览器和终端访问校园网站、运行 SSH；断开时，JustConnect 撤销自己管理的网络设置。内置复旦大学连接，也可添加自己的 aTrust 配置。

### 下载

| 系统 | 推荐 | 其他选项 |
| --- | --- | --- |
| Windows x64 | `JustConnect-v0.0.1-windows-x64-setup.exe` | `JustConnect-v0.0.1-windows-x64.zip` |
| Windows ARM64 | `JustConnect-v0.0.1-windows-arm64-setup.exe` | `JustConnect-v0.0.1-windows-arm64.zip` |
| macOS Apple Silicon | `JustConnect-v0.0.1-macos-arm64.dmg` | |
| macOS Intel | `JustConnect-v0.0.1-macos-x64.dmg` | |

Windows 安装程序只为当前用户安装，并添加开始菜单入口。ZIP 版需完整解压后运行 `JustConnect.exe`。两者均需 WebView2 Runtime。第一次连接按系统提示批准网络权限。

macOS 需要 14.4 或以上。打开 DMG，将 JustConnect 拖入「应用程序」。Windows 安装程序未使用商业代码签名证书，macOS 应用未公证；首次打开可能出现系统提示。请从本 Release 下载并按[首次启动说明](https://github.com/wtalioy/JustConnect/blob/v0.0.1/docs/DEVELOPMENT.md#不需申请签名的开发与发行)操作。

`SHA256SUMS.txt` 可校验下载完整性，`JustConnect-v0.0.1-source.tar.gz` 是与安装包对应的维护源码。
