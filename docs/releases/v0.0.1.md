This is the first public release of JustConnect, an open-source aTrust client for Windows and macOS.

## Download

| Platform | Install | Portable |
| --- | --- | --- |
| Windows · x64 | [Installer (.exe)](https://github.com/wtalioy/JustConnect/releases/download/v0.0.1/JustConnect-v0.0.1-windows-x64-setup.exe) | [ZIP](https://github.com/wtalioy/JustConnect/releases/download/v0.0.1/JustConnect-v0.0.1-windows-x64.zip) |
| Windows · ARM64 | [Installer (.exe)](https://github.com/wtalioy/JustConnect/releases/download/v0.0.1/JustConnect-v0.0.1-windows-arm64-setup.exe) | [ZIP](https://github.com/wtalioy/JustConnect/releases/download/v0.0.1/JustConnect-v0.0.1-windows-arm64.zip) |

- **Windows:** Run the installer to install JustConnect for your account. If you use the ZIP, extract the entire archive before opening `JustConnect.exe`.
- **macOS 14.4 or later:** Open the DMG and drag JustConnect to Applications.

Windows installers are unsigned, and macOS builds are not notarized. Your system may ask you to confirm the first launch.

## Connect

Select the built-in **Fudan University** profile, or add a profile for your own aTrust gateway. Click **Connect** and follow the sign-in and network permission prompts.
