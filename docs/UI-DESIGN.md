# 界面设计

JustConnect 使用原生窗口、实色浅底和共享 [Qt 样式表](../resource/appearance.qss)。设计稿已经由原生实现替代。当前版本、测试证据和待验收项集中在[计划 S7](../plan.md#s7-自动化ui-重设计与完整恢复)。

## 页面与职责

| 页面 | 主要操作与边界 |
| --- | --- |
| 首页和托盘 | 展示当前连接名称及真实连接状态，共享连接、取消、断开与恢复动作。首次启动选中 Fudan，预填服务器和网页登录方式，点击连接后才启动认证。首页的连接按钮和详情按钮并排等高。默认关闭到托盘，可选有序退出；无托盘时保留可访问的窗口。普通后台成功留在原处，必要认证才恢复窗口 |
| 应用设置 | 齿轮打开独立的全局设置。语言、关闭行为、启动偏好及 Clash 实例选择在这里调整。修改立即保存，失败回退；登录项系统调用在后台执行。控制器归属以原生检查为准 |
| 连接配置 | 首页连接菜单先列已保存的连接，再列编辑、添加、重命名、删除和当前连接的缓存操作。Fudan 是已配置的连接，编辑页展示其固定地址和端口。添加连接只创建同名空白配置，再填写自己的地址和登录方式。活动连接期间此页只读。自定义连接缺少配置时打开同一编辑页，成功保存后继续连接。导入、导出与重置位于固定页脚 |
| 连接详情 | 默认打开概览并聚焦页签。概览展示同一会话的入口、DNS、规则、出口和恢复状态，日志独立成页并保留最近 1,000 行。诊断复制只含允许字段和固定诊断码。两个复制按钮成功时在原位显示勾号，再自动恢复 |
| 网络保护 | 由首页菜单或连接详情的“网络保护”打开，自动读取地址和 DNS 来源，读取失败时提供重试。刷新期间保留同代的最近确认结果，换代或失败后清空。修改策略仍校验当前代次与服务器授权；页面仅展示已确认的策略范围 |
| 认证与恢复 | 统一登录、短信／MFA、可信设备和验证码的控件。提交和取消按当前挑战代次处理，语言切换保留认证输入。恢复责任未解除时保留重试入口，等待恢复完成后再开放连接 |

更新、项目主页、关于和退出归首页应用菜单。版本集中在“关于”，更新状态由更新检查器提供。主页、托盘、详情和认证共用现有会话、配置和权限模型。

## 共享控件

- 使用 4 px 间距节奏和统一的圆角。页签、菜单、下拉项和小工具采用中性灰悬停／选中反馈，强调色留给主要操作和连接图形。诊断行靠文字对齐，状态同时提供可读文字。
- 连接选择器随文字定宽，长名称可省略并保留完整可访问文本。输入框文字、尾部眼睛及下拉箭头按同一列对齐。服务器 CA 和域名 DNS 使用同样的常显多行输入框。下拉弹层优先对齐字段并在下方留出间距，空间不足时可向上打开。
- 工具栏沿用 18 px 圆角 SVG，意义明确的按钮保留可翻译提示和可访问名称。键盘焦点有可见反馈，复制动画遵循减少动画偏好。图标来源和分发许可见[资源映射](../resource/ICONS.md)与[许可](../resource/LICENSE.lucide)。
- 英文源码、简体中文和 Qt 标准按钮译文随同一资源部署。切换语言保留活动连接、认证输入和表单草稿，技术诊断保留固定代码。

## 认证浏览器选择

Windows 使用共享的 Evergreen WebView2 Runtime，macOS 使用 WKWebView。地址栏与前进、后退、刷新沿用共享图标，认证网页由服务器提供。Windows 缺少可用运行时时提示安装或更新。

每个认证窗口使用独立的 InPrivate 或非持久化存储。服务器 CA 和证书例外的作用域限于窗口及对应来源。主框架回调、Cookie 隔离、TLS 和取消由原生浏览器回归覆盖。现有网关依赖厂商 HTTPS 本机端点交换票据，默认浏览器交接方案受该端点的 TLS 身份约束。
