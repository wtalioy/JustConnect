# S7 界面设计

当前状态：2026-11-07 用户授权参考新效果图重做现有界面，要求进一步缩小字号、精简提示／按钮和冗余交互；不采用有色矩形文字标签或逐行图标，材质仅保留在首页顶部小区域，主要内容与对话框使用不透明浅底。共享样式、首页、设置、详情及认证窗口已调整；图标语义、输入框尾部操作、下拉箭头与表单对齐已通过两平台原生及四组实际包检查，实际桌面视觉／操作仍待验，S7 未完成。任务和验收状态由 [plan.md](../plan.md#s7-自动化ui-重设计与完整恢复)维护。

最新提案见[26 张效果图浏览页](../design/ui-concepts-2026-11-06/index.html)，[逐页提示词](../design/ui-concepts-2026-11-06/prompts.json)保留内置 image_gen 的生成输入。提案基于当前 Qt 窗口、动态认证交互、网络保护及菜单梳理，以浅色、靛蓝强调色、清晰排版和分组留白重新组织视觉；截图中的地址、端口、日志和学校网页均为示例。网页认证只设计应用外层，学校页面不属于应用重设计范围。效果图仅表达视觉提案，不证明功能、原生背景材质、缩放或键盘交互已经验收；此前实现与验证记录继续保留。

## 已确认方向

原生、简洁，有适度视觉设计感；本阶段只支持浅色。毛玻璃收敛到首页连续外壳：顶部与 8 px 细边相连，内缩的 8 px 圆角内容面板承载正文；提高浅灰蓝遮罩，降低透光程度；连接主体、详情、设置、认证及提示窗口保持不透明，优先保证清晰稳定，避免整窗透出桌面。优先使用系统原生背景效果；系统不提供效果时保持清晰的浅色界面，不自行逐帧模糊、不增加持续动画或常驻采集。保留系统窗口、菜单和键盘习惯。

默认 English，可在应用设置切换简体中文；语言与关闭行为不属于学校配置。首页减少常驻文字，优先学校、连接状态和一个主操作；字号与点击目标足够大，补充解释进入详情或仅在必要状态出现。主窗口保持紧凑，内容随缩放和长文案自然重排；图标、字号层级、留白、按钮及错误反馈在整套界面复用。

## 控件与比例

采用 4 px 间距节奏：正文与按钮 14 px、补充文字 12 px、首页状态 24 px；主要连接按钮居中、宽度约 156—196 px，保留 44 px 点击高度，普通按钮与输入约 40 px。靛蓝强调色保留给主操作与连接图形；普通控件焦点及悬停／选中统一使用柔和中性灰，状态使用普通文字，不放入绿色等矩形色块；诊断字段按文字对齐，不逐行配图标。控件与菜单统一 8 px 圆角，分组改用细线与留白。箭头使用 SVG，不依赖字体箭头的基线；原生标题栏只显示一次应用身份。

不同含义的操作不复用同一图标：校园选择使用校舍、原网络使用地球、实例使用服务节点、查询使用放大镜、规则使用列表；同义的刷新／复制在各页保持一致。语义清楚的操作只用图标，保留可翻译的悬停提示与可访问名称；复杂或影响连接的操作保留简短文字。工具栏图标 18 px、按钮约 40 px，带文字图标按钮保留 8 px 图文间距且仍使用可缩放矢量图；详情页的刷新／复制在同一组，规则与 DNS 单独靠右。

输入尾部使用较小的眼睛／斜线眼睛；显示切换不改输入，支持当前字段的 Ctrl+Shift+H（macOS 显示系统快捷键）。三种单行输入保持同样高度与文字起点，数字框按共享样式恢复 Qt 内嵌编辑器的文字边距；输入框动作不继承普通按钮最小高度；下拉箭头居中、数字上下箭头共用右侧对齐。按真实系统字体、窄窗口与缩放核对布局。

间距采用同一套 4 px 节奏：普通对话框外边距 24 px，浏览器外壳 16 px，设置／详情页内层不重复加外边距；章节间 20 px、内容间 12 px、表单行与工具按钮间 8 px、连续勾选项间 4 px。分组标题的留白由共享样式负责，内部布局不再叠加平台默认边距。连接设置中学校、认证及账户表单按当前语言的最长标签共享列宽，窄窗口仍允许换行；左右边界与底部操作区保持一致。

页签参考用户提供的 VS Code 胶囊式选择状态：当前项用中性灰圆角背景，悬停／按下沿同一灰阶加深，移除底部选择横线；工具图标平时保持透明，悬停显示浅灰圆角底色；纯图标 QPushButton 使用 flat，QToolButton 使用 autoRaise，原生状态也不显示常驻按钮边框。点选验证码将焦点放到图像，文本／点选切换随输入区域迁移焦点，重置箭头不抢初始焦点。小工具鼠标点击不取得持久焦点，键盘 Tab 仍可到达并显示中性灰细线；输入框尾部已有 NoFocus 动作不改变。菜单采用白色浮层、细边缘与内缩的 8 px 圆角选项，13 px 字号、6 px 上下留白；勾选与子菜单箭头各用固定 16 px 栏，向行内收 4 px，浮层左右留白 8 px，分隔线内缩；边缘与选中底色保持柔和。下拉列表复用同样的浮层与灰色选中，使用共享样式委托，避免平台默认菜单绘制忽略行内圆角；保留键盘选择、禁用项与系统浮层阴影。工具菜单、托盘、下拉项、页签及列表选中沿用同一灰阶。日志以 Cascadia Mono／Consolas／系统等宽字体回退，字号由共享样式维护。详情页两个页签都在内容顶端留 16 px，学校状态使用 14 px，状态到数据列表 16 px；诊断行内留白 12 px。工具操作不成为对话框默认提交，避免切换日志页后打开文件按钮误显主操作色。

界面动作采用固定来源的 Lucide 圆角 SVG，不引入运行依赖；[资源映射与版本](../resource/ICONS.md)、[完整许可](../resource/LICENSE.lucide)随源码保存，发行包携带许可。SSO 前进／后退／刷新与主界面共用这套图标；应用／托盘标识保留。

## 页面与职责

| 页面 | 用户操作与展示 |
| --- | --- |
| 首页 | 当前学校／配置、真实会话状态和一个主操作。连接覆盖认证、隧道和接管；处理中可取消，正常成功就地反馈。不重复展示状态或常驻说明，详细日志默认收起 |
| 配置管理 | 查看、新建、编辑、重命名、切换和删除配置；首次连接在同一设置页补齐服务器和认证方式后保存并连接。域名专用 DNS 直接编辑，配置更改不伪装当前会话已切换 |
| 应用设置 | 语言、窗口关闭行为、启动偏好及 Clash 实例选择。自动发现为默认，多实例可选择；手填本地控制地址仍需原生归属验证，不保存控制密钥 |
| 诊断 | 使用已有结构化事件展示入口、解析／命中／出口和恢复结果。未知如实标注；日志有界、脱敏，允许复制诊断信息 |
| 认证交互 | 必要时才展示并激活学校登录、账户输入、短信／MFA 或验证码。取消、超时、重试、隐藏窗口后返回与账户隔离保持现有契约 |
| 冲突与恢复 | 明确受影响的地址／范围及原网络保护选择；恢复失败提供现有重试入口，责任未撤销之前不允许重新连接 |
| 托盘与退出 | 与主窗口共享同一会话和操作；状态不只靠颜色。默认关闭到托盘，可选有序退出；无托盘时保持窗口可访问，明确 Exit 始终有序退出 |

整套实装包含主窗口、连接设置、登录与认证方式、SSO、短信／MFA、图形验证码、网络冲突、应用设置、诊断及更新／错误提示。学校网页本身不做视觉重写。认证浏览器先按 S7-13 完成交接可行性核对，再美化相应窗口，不从“可打开系统浏览器”推断能替代认证交换。

## 原型与实现边界

可点击原型仅模拟界面状态，不登录或修改系统网络。覆盖连接、取消、认证、冲突、恢复、无托盘、配置保存及活动连接时的语言切换；原型中的过程时间、地址和观测结果不是运行测量或产品默认。

原型已在 Qt WebEngine 中验证 736／320 像素布局和操作，关键截图及断言归 `build/reports/s7-ui-prototype/`。用户已确认按此版实装、细节继续优化；原生实现对应 S7-06／09／11／12。原型不进入产品运行链路；Qt 状态仍从现有 ConnectionSession、CoreEngine、配置服务和系统能力派生，不增加一套业务后端。

## 原生实装进度

首页沿用原生标题栏显示一次应用身份，内容区去掉重复 Logo／名称，顶部保留 24 px 外边距，使用 36 px 高／16 px 字号的自然宽度学校选择与独立的 22 px 设置图标；校名与箭头间距单独控制，文字宽度保留小数并向上取整，长名称省略但保留完整可访问文本，移除页头分隔线；学校标签从统一的展示映射翻译，保存的身份值不变，下面是实时状态和主操作；参考 [qBittorrent 主窗口](https://github.com/qbittorrent/qBittorrent/blob/master/src/gui/mainwindow.ui)与 [KeePassXC 主窗口](https://github.com/keepassxreboot/keepassxc/blob/develop/src/gui/MainWindow.ui)的标题栏／工作区分工，命名配置与可访问名称从当前设置派生，设置收在齿轮入口；日志与维护观察移入独立详情窗口。详情与托盘仍读取同一个会话，打开／关闭详情不改变连接；连接／断开使用居中的紧凑主按钮，下方是轻量的“详情”文字入口，删除旧页脚分隔与整行箭头，关闭复用原生窗口按钮，明确退出仍在菜单。公共浅色样式统一按钮、箭头、字号、输入及焦点反馈，替换并删除旧的三份主窗口样式，移除 Windows 固定字体。

仅主窗口显式启用系统背景：Windows 使用 Desktop Acrylic 并保留标准窗口边框，macOS 使用 NSVisualEffectView；首页连接主体内缩 8 px，单独绘制不透明浅底与 8 px 圆角；顶部与四周细边形成连续外壳，避免横切一块材质。浅灰蓝叠层 alpha 为 235/255，降低桌面干扰，其余窗口不启用透明背景。材质上的学校选择与工具悬停使用半透明灰，不叠纯白色块。只在实际 Windows／Cocoa Qt 后端使用原生句柄，离屏等后端走清晰浅色回退。没有应用侧屏幕采集、逐帧模糊或持续动画。实现依据为 [DWM 背景材质](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)及系统 AppKit；Windows 不支持该能力时回退浅色，不叠加旧版本私有 API。系统效果尚待对应桌面验证，不能用 离屏截图证明毛玻璃已生效。

首页、详情及认证窗口的合成数据截图归 `build/reports/s7-native-ui/`；学校／配置名称、长文案和配置操作截图归 `build/reports/s7-profile-ui/`。它们证明离屏布局与交互，不证明实际桌面效果。

应用设置为紧凑的原生窗口，语言与关闭行为由全局存储一次保存；失败保留原值。主窗口、详情、托盘、实例选择及登录／SSO／验证码／MFA 已接入英文源码和 Qt 中文目录，Qt 标准按钮文案与应用目录通过 Qt 的 `MERGE_QT_TRANSLATIONS` 一并编入资源，单个翻译器完成语言切换，不依赖目标电脑的翻译目录；删除 macOS 手工复制全部 Qt 按钮语言的旧脚本。连接动作由原有协调器中的单一映射维护，维护观察不重复刷新未变的样式；切换语言不改配置或连接。平台技术诊断统一英文，与固定诊断码共同保留在日志；用户操作提示由界面按类型状态翻译，不将翻译框架引入网络后端。启动偏好失败由类型状态生成本地化提示，语言切换重新生成提示，原始平台诊断记录到日志。实际桌面的语言与整套操作仍待验收。主按钮、托盘、自动连接及首次配置保存成功均向同一协调器交付显式意图，不再模拟按钮点击；保存失败或取消不启动连接。必要认证恢复隐藏／最小化的窗口，普通后台操作不抢焦点，托盘恢复保留最大化状态。

连接配置与应用设置的表单标签随同一行字段分配完整高度，避免 Qt 表单将标签限制在输入框上半部；窄窗仍按原规则换行。学校 CA 使用左侧标题与右侧展开按钮，编辑区与 DNS 区域对齐，折叠保留证书草稿。

认证窗口统一控件、间距和操作尺寸，登录与验证码等小窗采用约 400 px 宽度；密码与认证器密钥使用输入框尾部眼睛动作，替代单独的显示勾选项。登录缺少账户／密码时禁用提交，Unicode 原样提交，不再追加字符集确认。保留输入、勾选与挑战代次；切换语言不重载学校页面。移除了根据学校名称猜测 OAuth 项的逻辑，唯一方式可预选、多项须明确选择。点选验证码支持方向键、空格、退格和有界原图坐标，鼠标与键盘复用同一选点上限。回调／TLS／Cookie／取消回归与实时翻译、控件边界和键盘检查共同保留。

齿轮仅打开独立的“应用设置”：语言、关闭行为、开机／后台启动与 Clash 实例属于全局偏好，更改立即保存，失败回退控件和存储。学校选择以有轻微底色的紧凑圆角控件将文字与箭头合为一体，36 px 高、16 px 字号，宽度随文字自适应，超长名称不撑开窄窗；学校菜单只选择、创建、重命名、删除和编辑连接。“编辑连接”打开独立的“连接配置”，没有应用偏好页签；提供服务器、认证方式、凭据和本连接行为。连接期间应用偏好仍可改，当前连接配置只读。连接配置只提供“保存／取消”，保存成功后关闭并用于下次连接；域名专用 DNS 直接可见，认证方式原地查询／取消／重试，手机号仅在短信方式显示。导入／导出／重置仍属当前连接，安全校验与凭据所有权不变。

删除独立三步配置引导及认证方式弹窗。首次缺少配置时点击连接会直接打开同一个连接页，保存成功后继续原连接意图；取消或保存失败不连接，也不再弹欢迎确认。删除端口、网卡绑定、DNS 缓存／备用来源、手工系统代理、重连时间与自定义保活等日常控件；完整公开配置草稿仍由既有配置模块维护，编辑可见字段不会重置已保存的高级值。独立界面的专属测试退出，保留并迁移实际查询／取消／TLS、凭据隔离、保存失败、导入／导出／重置、短屏和双语回归。

原生毛玻璃采用 Windows DWM／macOS NSVisualEffectView，无自绘模糊或持续动画。统一窗口外观在 widget 构造完成的 Create 事件准备透明属性，早于原生句柄创建；安装外观时已存在的主窗口也显式准备。Qt 据此创建 alpha 缓冲并清除局部旧帧，不依赖过晚的 Polish／Show 或额外背景绘制；显示时重新应用当前原生句柄的背景，macOS 复用同一效果视图。回归只在真实 Paint 期间复制已绘制区域；macOS IOSurface 在绘制结束后会解锁／轮换，不能在此后将 paintDevice 当成当前帧读取。它直接检查 backing store，避免 `grab()` 的重新绘制掩盖残影；Details 连续开关与高 DPI 首页走真实桌面后端。实现依据为 [Qt 的透明窗口格式时序](https://github.com/qt/qtbase/blob/v6.12.0/src/widgets/kernel/qwidget.cpp)及 [Windows backing-store 清屏条件](https://github.com/qt/qtbase/blob/v6.12.0/src/plugins/platforms/windows/qwindowsbackingstore.cpp)。

网络保护窗口已统一地址／DNS 来源页、操作与提示；英文／中文切换保留选中范围、已输入地址及当前策略代次。确认／取消采用 Qt 标准按钮，认证与保护输入复用对话框重翻译组件，保留严格地址／名称校验、旧代次拒绝、失败恢复及原始来源区分。公开头文件不再包含生成的 UI 头。

更新状态由检查器的类型状态与真实版本值维护，语言切换由展示层派生文案；移除会被状态刷新覆盖的平行失败提示。认证缓存警告复用 Qt 翻译，保留账户绑定与失效语义。

诊断详情收敛为“概览／日志”两个同级页签；默认显示状态，日志及复制／清空／打开文件操作归日志页，帮助、清理缓存与退出收进工具菜单。删除手动设置／清除系统代理按钮及对应应用控制链、覆盖确认和自动设置偏好；代理会话仅接受带原代理来源的自动交接，不再提供手动应用或冲突预览。Clash 共存的原生交接、外部变更观察与按所有权恢复继续由同一模块负责，恢复 journal／独立守护仍有实际调用，不因界面精简删除。诊断复用现有会话、网络保护与核心共存快照，展示本地入口端口、校园 DNS、规则／重叠与校园例外、已确认出口策略和恢复状态；“规则与 DNS”打开同一来源／重叠详情。它展示确认过的策略，不将规则数量当作某条流量的命中证明。首次无结果、查询失败及旧代次明确显示未知；同代刷新中保留最近确认的展示，变化完成后一次更新，表格复用原有行，业务模型和操作门槛仍以当前读取状态为准，不新增周期查询或数据面日志；详情关闭时不刷新显示，复制仅含允许字段与固定诊断码。诊断脱敏、失效观察、语言切换、复制及无额外读取由已有应用测试覆盖；宽字体窄窗口、长配置名和首页 Tab 到主操作保留回归。认证／配置操作回归分别按 200%／150% 缩放运行；共享外观回归在正常与 200% 缩放检查眼睛／清除、下拉和数字操作的实际几何位置，防止样式继承导致偏移。

验证与交付范围：双语、Qt 标准按钮、原生认证页面、运行库／助手来源及实际包体积由应用回归与包检查共同验证；对应源码、CI 和未验收项只在 [计划 S7](../plan.md#s7-自动化ui-重设计与完整恢复) 维护。Windows 集中操作及毛玻璃效果尚待用户实测；交互原型保留到视觉验收通过，macOS 桌面留 S8。

## 认证浏览器选择

为减小包体积，登录窗口改用 Windows 共享 Evergreen WebView2 Runtime 与 macOS 系统 WKWebView，不再随包分发 Chromium。保留现有地址栏、前进／后退／刷新和认证会话接口；两种原生实现归 `presentation/browser/{windows,macos}`，回调校验仍由同一登录窗口及核心认证边界负责。Windows 缺少可用 WebView2 时明确提示安装／更新，不回退到另一套内置引擎。

每个窗口独立使用 InPrivate／非持久化数据存储，不读取默认浏览器 Cookie；Windows 的独立临时环境已隔离账户，直接使用其中的默认 profile，不再额外创建随机命名的 profile；学校 CA 与网关例外只作用于该窗口，不安装系统根、不改变全局信任。保留真实页面、JavaScript、Cookie 隔离、主框架回调拦截与 TLS 来源边界回归，并在原生桌面后端运行；离屏测试不能证明原生网页可用。实际包验证同时启动所选浏览器，报告压缩包、解压及主要文件体积。实现与原生／包验收状态只在 S7-13 维护。

直接打开默认浏览器的公开交接调查已结束：当前网关拒绝测试过的独立回调，门户通过厂商 HTTPS 本机端点交换票据。独立客户端不能仅注册 URL 协议便取得该 TLS 身份；不为减包增加浏览器扩展、调试协议、常驻中转服务或手工票据操作。用户已同意以应用内系统引擎完成目标。

本轮详情概览采用无逐行图标的两列文字列表，与复制报告共用诊断字段来源；旧纯文本框删除，维护观察移入日志页，版本与工具位于公共页脚。设置、详情与认证对话框整体不透明，系统背景材质仅保留在首页顶部与四周细边；不以离屏截图或带透明通道的控件截图证明实际桌面毛玻璃已验收。
