# S7 界面设计

当前状态：视觉方向与修订交互原型均已由用户确认；本文不表示 Qt 实装或 S7 已完成。任务和验收状态由 [plan.md](../plan.md#s7-自动化ui-重设计与完整恢复)维护。

## 已确认方向

原生、简洁，有适度视觉设计感；本阶段只支持浅色。毛玻璃应有可感知的模糊与透光层次，内容和文字保持清晰；不以接近不透明的浅色面板代替效果。优先使用系统原生背景效果；系统不提供效果时保持清晰的浅色界面，不自行逐帧模糊、不增加持续动画或常驻采集。保留系统窗口、菜单和键盘习惯。

默认 English，可在应用设置切换简体中文；语言与关闭行为不属于学校配置。首页减少常驻文字，优先学校、连接状态和一个主操作；字号与点击目标足够大，补充解释进入详情或仅在必要状态出现。主窗口保持紧凑，内容随缩放和长文案自然重排；图标、字号层级、留白、按钮及错误反馈在整套界面复用。

## 控件与比例

采用 4 px 间距节奏：主要按钮／输入的点击高度至少 44 px，正文与按钮文字以 16 px 为基准，连接状态 30 px。箭头使用定尺寸 SVG 并与文字在同一弹性行居中，不依赖字体箭头的基线。主／次按钮同高并统一内边距；按钮 10 px、输入 8 px、对话框 14 px、窗口 18 px 圆角分层，避免同层控件半径散乱。页内行距、标签与输入间距、图标尺寸及返回入口统一；短按钮与长中英文文案均验证实际布局。数值是当前原型基线，Qt 实装按真实系统字体与缩放核对。

## 页面与职责

| 页面 | 用户操作与展示 |
| --- | --- |
| 首页 | 当前学校／配置、真实会话状态和一个主操作。连接覆盖认证、隧道和接管；处理中可取消，正常成功就地反馈。不重复展示状态或常驻说明，详细日志默认收起 |
| 配置管理与引导 | 查看、新建、编辑、重命名、切换和删除配置；首配串联服务器、实际认证方式查询、保存及连接。域名专用 DNS 等高级项按需展开，配置更改不伪装当前会话已切换 |
| 应用设置 | 语言、窗口关闭行为、启动偏好及 Clash 实例选择。自动发现为默认，多实例可选择；手填本地控制地址仍需原生归属验证，不保存控制密钥 |
| 诊断 | 使用已有结构化事件展示入口、解析／命中／出口和恢复结果。未知如实标注；日志有界、脱敏，允许复制诊断信息 |
| 认证交互 | 必要时才展示并激活学校登录、账户输入、短信／MFA 或验证码。取消、超时、重试、隐藏窗口后返回与账户隔离保持现有契约 |
| 冲突与恢复 | 明确受影响的地址／范围及原网络保护选择；恢复失败提供现有重试入口，责任未撤销之前不允许重新连接 |
| 托盘与退出 | 与主窗口共享同一会话和操作；状态不只靠颜色。默认关闭到托盘，可选有序退出；无托盘时保持窗口可访问，明确 Exit 始终有序退出 |

整套实装包含主窗口、配置引导／编辑、登录与认证方式、SSO、短信／MFA、图形验证码、网络冲突、应用设置、诊断及更新／错误提示。学校网页本身不做视觉重写。认证浏览器先按 S7-13 完成交接可行性核对，再美化相应窗口，不从“可打开系统浏览器”推断能替代认证交换。

## 原型与实现边界

可点击原型仅模拟界面状态，不登录或修改系统网络。覆盖连接、取消、认证、冲突、恢复、无托盘、配置保存及活动连接时的语言切换；原型中的过程时间、地址和观测结果不是运行测量或产品默认。

原型已在 Qt WebEngine 中验证 736／320 像素布局和操作，关键截图及断言归 `build/reports/s7-ui-prototype/`。用户已确认按此版实装、细节继续优化；接下来按 S7-06／09／11／12 实装。原型不进入产品运行链路；Qt 状态仍从现有 ConnectionSession、CoreEngine、配置服务和系统能力派生，不增加一套业务后端。

## 原生实装进度

首页已改为紧凑单列：学校选择、真实状态和主按钮，设置收在齿轮入口；日志、维护观察和高级代理操作移入独立详情窗口。详情与托盘仍读取同一个会话，打开／关闭详情不改变连接。公共浅色样式统一按钮、箭头、字号、输入及焦点反馈，替换并删除旧的三份主窗口样式，移除 Windows 固定字体。

Windows 请求系统 Desktop Acrylic 并保留标准窗口边框；macOS 使用 NSVisualEffectView，Linux 当前使用清晰浅色回退。只在实际 Windows／Cocoa Qt 后端使用原生句柄，离屏等后端走清晰浅色回退。没有应用侧屏幕采集、逐帧模糊或持续动画。实现依据为 [DWM 背景材质](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)及系统 AppKit；Windows 不支持该能力时回退浅色，不叠加旧版本私有 API。系统效果尚待对应桌面验证，不能用 Linux 离屏截图证明毛玻璃已生效。

本地已验证 9 项主窗口操作回归、详情／日志复制及 320 px 首页布局；截图归 `build/reports/s7-native-ui/`。当前不是完整 UI 验收：配套窗口和诊断汇总已接入，Windows 实机操作仍按 S7-06—12 继续推进。

应用设置为紧凑的原生窗口，语言与关闭行为由全局存储一次保存；失败保留原值。主窗口、详情、托盘、实例选择及登录／SSO／验证码／MFA 已接入英文源码和 Qt 中文目录，标准按钮随语言切换。连接动作由原有协调器中的单一映射维护，维护观察不重复刷新未变的样式；切换语言不改配置或连接。底层跨平台错误文案仍待收尾，不记为全套双语完成。主按钮、托盘、自动连接及引导保存成功均向同一协调器交付显式意图，不再模拟按钮点击；保存失败或取消不启动连接。必要认证恢复隐藏／最小化的窗口，普通后台操作不抢焦点，托盘恢复保留最大化状态。

认证窗口统一控件、间距和操作尺寸，保留输入、勾选与挑战代次；切换语言不重载学校页面。移除了根据学校名称猜测 OAuth 项的逻辑，唯一方式可预选、多项须明确选择。点选验证码支持方向键、空格、退格和有界原图坐标，鼠标与键盘复用同一选点上限。已有回调／TLS／Cookie／取消回归及新增实时翻译、控件边界和键盘检查通过本地相关操作测试，本轮全量重建后 71 项应用检查通过；截图为合成数据，报告 `build/reports/s7-native-ui/`。

配置引导已改为学校／服务器、认证方式、账号三步，标题 24 px；首步与编辑页共用折叠式服务器表单，高级 DNS／CA／证书选项默认收起，关闭验证时仍展示风险摘要。英文／中文切换不改变步骤、服务器、DNS 草稿、认证 ID 或凭据输入；320 px 首步无横向裁切，下拉框按可用宽度收缩，宽回退字体指标也不撑大表单。完整重建后 16 项相关操作回归通过，截图与报告归 `build/reports/s7-profile-ui/`；实际桌面效果仍待验。

配置编辑采用同一服务器表单和三页可滚动布局，手工代理归高级页；密码显示控件合并到输入行，页签由 `.ui` 管理，删除运行时拆装。实时翻译保留当前页、认证方式与 opaque ID、凭据草稿、显示选项及保活目标；实际保存、失败、取消、导入／导出、认证缓存和短屏键盘滚动的回归保留。本轮完整重建后 72 项本地应用检查通过，新源码跨平台 CI 与 Windows 集中实测待验。

网络保护窗口已统一地址／DNS 来源页、操作与提示；英文／中文切换保留选中范围、已输入地址及当前策略代次。确认／取消采用 Qt 标准按钮，认证与保护输入复用对话框重翻译组件，保留严格地址／名称校验、旧代次拒绝、失败恢复及原始来源区分。公开头文件不再包含生成的 UI 头；全新目录构建和 73 项检查通过。Windows 实机验收仍待完成。

更新状态由检查器的类型状态与真实版本值维护，语言切换由展示层派生文案；移除会被状态刷新覆盖的平行失败提示。认证缓存警告复用 Qt 翻译，保留账户绑定与失效语义。本地完整重建后 16 项更新／主窗口／协议与认证缓存回归通过。

诊断详情复用现有会话、网络保护与核心共存快照，展示本地入口端口、校园 DNS、规则／重叠与校园例外、已确认出口策略和恢复状态；“规则与 DNS”打开同一来源／重叠详情。它展示确认过的策略，不将规则数量当作某条流量的命中证明。无结果、查询失败及旧代次明确显示未知，不新增周期查询或数据面日志；详情关闭时不刷新显示，复制仅含允许字段与固定诊断码。诊断脱敏、失效观察、语言切换、复制及无额外读取覆盖于本地 74 项应用检查；最终布局与宽字体窄窗口补验通过，截图归 `build/reports/s7-profile-ui/`。

## 认证浏览器选择

当前版本保留 WebEngine。2026-11-05 对现有网关公开认证配置及 IdP 入口作匿名、校验证书的只读核对：当前 OAuth 客户端只公布网关 HTTPS 回调；原始入口正常重定向，保持同一客户端、仅将回调改为短时回环地址时，IdP 明确返回 `21004 / redirect_uri 非法`。这证明当前已配置客户端不接受该原生回调，不能用“打开系统浏览器”替代由核心会话交换一次性 code 的交接。不据此推断所有自定义网关都不支持原生客户端。

不增加票据复制、浏览器插件或另一套登录后端。继续使用现有独立登录页面及结构化认证协调器，保留精确回调路径／参数、一次性交付、账户与 TLS、取消及旧代次隔离回归。认证窗口的外观按本设计改造，学校网页自身不重写。未来只有服务端提供可验证的自动交接契约，才重新评估替换；WebEngine 仍有正式调用，不删除相关资源、依赖和有效回归。

证据：`build/reports/s7-browser-handoff/{public-config,redirect-comparison}.json` 只保留公开能力与脱敏结果，不含 Cookie、凭据或会话票据。现有 Windows／Fudan 登录操作基线及全平台自动回归继续有效；没有实现或宣称通过外部浏览器的完整认证交接。

## 验收

逐窗口验证中英文、键盘焦点与可访问名称、长文案／错误、高 DPI、取消及旧结果隔离。Windows 中途进行真实操作验收；macOS／Linux 桌面、实际注销等按既定约定留 S8。性能只按真实测量记录，不以原型流畅、微基准或编译成功代替实际网络、CPU／内存及操作验证。
