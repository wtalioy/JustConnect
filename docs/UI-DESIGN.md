# S7 界面设计

当前状态：视觉方向已由用户确认，交互原型待确认；本文不表示 Qt 实装或 S7 已完成。任务和验收状态由 [plan.md](../plan.md#s7-自动化ui-重设计与完整恢复)维护。

## 已确认方向

原生、简洁，有适度视觉设计感；本阶段只支持浅色。毛玻璃应有可感知的模糊与透光层次，内容和文字保持清晰；不以接近不透明的浅色面板代替效果。优先使用系统原生背景效果；系统不提供效果时保持清晰的浅色界面，不自行逐帧模糊、不增加持续动画或常驻采集。保留系统窗口、菜单和键盘习惯。

默认 English，可在应用设置切换简体中文；语言与关闭行为不属于学校配置。首页减少常驻文字，优先学校、连接状态和一个主操作；字号与点击目标足够大，补充解释进入详情或仅在必要状态出现。主窗口保持紧凑，内容随缩放和长文案自然重排；图标、字号层级、留白、按钮及错误反馈在整套界面复用。

## 控件与比例

采用 4 px 间距节奏：主要按钮／输入的点击高度至少 44 px，正文与按钮文字以 16 px 为基准，连接状态 30 px。箭头使用定尺寸 SVG 并与文字在同一弹性行居中，不依赖字体箭头的基线。主／次按钮同高并统一内边距；按钮 10 px、输入 8 px、对话框 14 px、窗口 18 px 圆角分层，避免同层控件半径散乱。页内行距、标签与输入间距、图标尺寸及返回入口统一；短按钮与长中英文文案均验证实际布局。数值是当前原型基线，Qt 实装按真实系统字体与缩放核对。

## 页面与职责

| 页面 | 用户操作与展示 |
| --- | --- |
| 首页 | 当前学校／配置、真实会话状态和一个主操作。连接覆盖认证、隧道和接管；处理中可取消，正常成功就地反馈。不重复展示状态或常驻说明，详细日志默认收起 |
| 配置管理与引导 | 查看、新建、编辑、重命名、切换和删除配置；首配串联服务器、实际认证方式查询、保存及连接。域名专用 DNS 等高级项按需展开，配置更改不伪装当前会话已切换 |
| 应用设置 | 语言、窗口关闭行为、启动偏好及 Clash 实例选择。自动发现为默认，多实例可选择；手填本地控制地址仍需原生归属验证，不保存控制密钥 |
| 诊断 | 使用已有结构化事件展示入口、解析／命中／出口和恢复结果。未知如实标注；日志有界、脱敏，允许复制诊断信息 |
| 认证交互 | 必要时才展示并激活学校登录、账户输入、短信／MFA 或验证码。取消、超时、重试、隐藏窗口后返回与账户隔离保持现有契约 |
| 冲突与恢复 | 明确受影响的地址／范围及原网络保护选择；恢复失败提供现有重试入口，责任未撤销之前不允许重新连接 |
| 托盘与退出 | 与主窗口共享同一会话和操作；状态不只靠颜色。默认关闭到托盘，可选有序退出；无托盘时保持窗口可访问，明确 Exit 始终有序退出 |

整套实装包含主窗口、配置引导／编辑、登录与认证方式、SSO、短信／MFA、图形验证码、网络冲突、应用设置、诊断及更新／错误提示。学校网页本身不做视觉重写。认证浏览器先按 S7-13 完成交接可行性核对，再美化相应窗口，不从“可打开系统浏览器”推断能替代认证交换。

## 原型与实现边界

可点击原型仅模拟界面状态，不登录或修改系统网络。覆盖连接、取消、认证、冲突、恢复、无托盘、配置保存及活动连接时的语言切换；原型中的过程时间、地址和观测结果不是运行测量或产品默认。

原型已在 Qt WebEngine 中验证 736／320 像素布局和操作，关键截图及断言归 `build/reports/s7-ui-prototype/`。需要用户确认信息结构和交互后，再按 S7-06／09／11／12 实装。原型不进入产品运行链路；Qt 状态仍从现有 ConnectionSession、CoreEngine、配置服务和系统能力派生，不增加一套业务后端。

## 验收

逐窗口验证中英文、键盘焦点与可访问名称、长文案／错误、高 DPI、取消及旧结果隔离。Windows 中途进行真实操作验收；macOS／Linux 桌面、实际注销等按既定约定留 S8。性能只按真实测量记录，不以原型流畅、微基准或编译成功代替实际网络、CPU／内存及操作验证。
