`chevron-right.svg` rotates the existing Lucide chevron. `check.svg`, `menu.svg`, and `stop.svg` are geometric marks drawn for the application. `icon.svg` and the connection-state illustrations are JustConnect artwork.

`JustConnect.ico` packages RGBA PNG renders of the transparent `icon.svg` link at native Windows icon sizes. Windows uses the link for its window caption, Start menu shortcut, and taskbar. Linux uses `icon.svg` for its desktop entry and window icon. Finder and the Dock use the tiled `JustConnect.icns`, while About renders its source `app-icon.svg` directly. The Windows tray uses the colored link at rest and `connection-ready.svg` when connected. The macOS menu bar uses `tray-link.svg` and `tray-link-ready.svg` as monochrome templates tinted by AppKit. Prompts use the local `prompt-question.svg`, `prompt-info.svg`, and `prompt-warning.svg` marks. The update notice uses the application icon.
